# AI-Powered Resume Intelligence Platform

## Overview
An AI-driven platform that helps recruiters and job seekers make smarter hiring decisions by analyzing resumes and job descriptions using **NLP and Machine Learning**.  
It goes beyond keyword matching by understanding context, providing match scores, skill gaps, and actionable insights.

---

## Features
- Upload PDF or text resumes
- Paste a job description
- AI extracts skills and analyzes content
- Provides **match score (%)**
- Highlights matched skills, missing skills, and improvement suggestions
- Ranks multiple resumes for the same job
- **Explainable AI insights** – shows why candidates match

---

## Tech Stack
- **Language:** Python  
- **NLP:** spaCy, TF-IDF, Cosine Similarity  
- **Data Handling:** pdfplumber, pandas  
- **Machine Learning:** Scikit-learn  
- **Web UI:** Streamlit  
- **Model Persistence:** joblib
